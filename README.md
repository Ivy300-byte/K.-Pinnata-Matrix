# K. Pinnata Matrix

A creation of a HeteroGNN model tailored to Bryophyllum Pinnatum for precise mapping of secondary metabolited. I am designing this to be a multi-layered topological GNN, where the base of the arhcitecture would be the diagramatic links of the parts of Crassulacean Acid Metabolism. The part of my topology would consist of the mathematical weights of which will instantiate the model, and the final part of the topology would be the data on the secondary metabolites found in Bryophyllum Pinnatum and their chemical properties. 


Here you will notice that there is not much code to go along with this project as of late. This is because the majority of the code for this work will take a while to produce. Right now I've posted the code bases related to the construction of my base topology for my HeteroGNN. The names of these in my repository are HeteroCovert and CAM Pathway Topology. I’m currently mathematically deriving the framework by hand, and I realize now that there’s a lot of equations I still need to find, mainly from scientific papers of which most of the frameworks can be found.

While there may not be much code to present at this time, There is currently all the iterations I’ve made for the work going back all they to its origins up the where it is now.
